# Подбор гиперпараметров, кросс-валидация, сравнение моделей

## Инструкция

1. Создайте окружение Python - `conda create -n "week_8" python=3.11`
2. Активируйте окружение Python - `conda activate week_8`
3. установите библиотеки из requirements.txt - `pip install -r requirements.txt`
4. Скачайте датасет [train.csv](https://www.kaggle.com/datasets/marcopale/housing?select=train.csv),
создайте папку data/ и поместите туда train.csv.

## ОСОБЫЕ ПРИМЕЧАНИЯ

Есть 5 наблюдений, которые преподавателю, возможно, стоит удалить из набора данных перед передачей студентам (график SALE PRICE против GR LIV AREA быстро их покажет). Три из них являются истинными выбросами (частичные продажи, которые, вероятно, не отражают реальные рыночные стоимости), а два — просто необычные продажи (очень большие дома, оценённые относительно адекватно). Я бы рекомендовал удалить любые дома площадью более 4000 квадратных футов из набора данных (это устраняет эти 5 необычных наблюдений) перед назначением его студентам.

## ИСТОРИЯ ДАННЫХ

Этот набор данных был создан для целей итогового проекта семестра по курсу бакалаврской регрессии. Исходные данные (полученные непосредственно из офиса оценщика Эймса) используются для целей налоговой оценки, но непосредственно подходят для прогнозирования цен продажи домов. Тип информации, содержащейся в данных, аналогичен тому, что типичный покупатель дома хотел бы знать перед покупкой, и студенты должны найти большинство переменных простыми и понятными.

## ПЕДАГОГИЧЕСКИЕ ПРИМЕЧАНИЯ

Преподавателям, не знакомым с множественной регрессией, возможно, стоит использовать этот набор данных вместе с более ранней статьёй JSE, в которой рассматриваются большинство основных проблем, встречающихся при регрессионном моделировании:

Kuiper, S. (2008), “Introduction to Multiple Regression: How Much Is Your Car Worth?”, Journal of Statistics Education Volume 16, Number 3 (2008).

Помимо общих вопросов, связанных с множественной регрессией, обсуждаемых в этой статье, этот конкретный набор данных предлагает несколько возможностей обсудить, как цель модели может влиять на тип выполняемого моделирования. Пользователям этих данных также может быть полезно ознакомиться с другой статьёй JSE, непосредственно связанной с ценообразованием недвижимости:

Pardoe, I. (2008), “Modeling home prices using realtor data”, Journal of Statistics Education Volume 16, Number 2 (2008).

Один из вопросов касается гомоскедастичности и нарушений предположений. График, включённый в статью, по-видимому, указывает на гетероскедастичность с увеличением вариации с ростом цены продажи, и эта проблема очевидна во многих простых моделях ценообразования домов, которые фокусируются только на размерах дома и участка. Хотя это нарушение можно смягчить путём преобразования переменной отклика (цены продажи), полученное уравнение даёт трудно интерпретируемые подогнанные значения (цена продажи в логарифмических или квадратных долларах). Эта ситуация даёт преподавателю возможность поговорить о затратах (смещённые оценки, неверные статистические тесты и т. д.) и выгодах (простота использования) отказа от исправления этого нарушения предположения. Если цель построения модели — просто позволить типичному покупателю или агенту по недвижимости сесть и оценить цену продажи дома, такие преобразования могут быть ненужными или неуместными для данной задачи. Этот вопрос также может открыть дискуссию о контрастах и сравнениях между data mining, прогнозными моделями и формальным статистическим выводом.

Вторая проблема, тесно связанная с предполагаемым использованием модели, — это обработка выбросов и необычных наблюдений. В целом я инструктирую своих студентов никогда не выбрасывать точки данных только потому, что они не соответствуют априорным ожиданиям (или другим точкам данных). Я strongly подчёркиваю это в ситуации, когда данные анализируются для исследовательских целей, которые будут shared с более широкой аудиторией. С другой стороны, если цель — снова создать модель общего использования для оценки «типичной» продажи, в интересах моделировщика удалить любые наблюдения, которые не кажутся типичными (например, foreclosure или семейные продажи).

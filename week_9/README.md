# Демонстрация PCA и Truncated SVD на датасете Ames Housing

## Инструкция

1. Создайте окружение Python - `conda create -n "week_9" python=3.11`
2. Активируйте окружение Python - `conda activate week_9`
3. установите библиотеки из requirements.txt - `pip install -r requirements.txt`
4. Скачайте датасет [Bank Customer Behavior & Churn Dataset](https://www.kaggle.com/datasets/thuandao/bank-customer-behavior-and-churn-dataset#1) и поместите в папку data/

## Датасет Bank Customer Behavior & Churn Dataset

Этот набор данных содержит 80 000 смоделированных записей о клиентах банка, предназначенных для аналитики, практики проектирования данных и экспериментов в области машинного обучения. Каждая запись представляет собой отдельного клиента и включает демографические характеристики, финансовую информацию, показатели использования услуг, индикаторы вовлеченности и оценки риска. Набор данных отражает различные аспекты взаимоотношений клиентов с банком, такие как баланс счета, кредитный рейтинг, количество используемых продуктов, цифровая активность и история взаимодействия.


| Поле | Описание |
|---|---|
| `id` | Уникальный идентификатор каждого клиента. |
| `full_name` | Имитированное полное имя клиента. |
| `credit_sco` | Кредитный рейтинг клиента, отражающий его кредитоспособность. |
| `gender` | Пол клиента. |
| `age` | Возраст клиента. |
| `occupation` | Категория занятости клиента. |
| `balance` | Текущий баланс счета клиента. |
| `monthly_ir` | Предполагаемый ежемесячный доход клиента. |
| `address` | Город или населенный пункт, где клиент в настоящее время проживает. |
| `origin_province` | Провинция происхождения клиента. |
| `tenure_ye` | Количество лет, в течение которых клиент является клиентом банка. |
| `married` | Показатель семейного положения. |
| `nums_card` | Количество банковских карт, принадлежащих клиенту. |
| `nums_service` | Количество банковских услуг, используемых клиентом. |
| `active_member` | Указывает, активно ли клиент пользуется банковскими услугами. |
| `last_active_date` | Последняя дата активности клиента. |
| `last_transaction_month` | Денежная сумма или показатель активности, зафиксированный в последнем месяце транзакций. |
| `created_date` | Дата создания счета клиента. |
| `exit` | Логический индикатор, показывающий, покинул ли клиент банк. |
| `customer_segment` | Классификация сегмента клиента (например, Standard, Premium и т. д.). |
| `engagement_score` | Показатель, отражающий уровень вовлеченности клиента в работу с банком. |
| `loyalty_level` | Классификация лояльности, основанная на вовлеченности и стаже. |
| `digital_behavior` | Индикатор, описывающий, активно ли клиент использует цифровые банковские каналы. |
| `risk_score` | Расчетный показатель, оценивающий потенциальный финансовый риск или риск оттока клиентов. |
| `risk_segment` | Классификация риска, полученная на основе оценки риска. |
| `cluster_group` | Метка кластера клиентов, сгенерированная с использованием методов сегментации или кластеризации. |

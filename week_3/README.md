# Визуализация данных

## Инструкция

1. Создайте папку data и поместите туда файл [check.csv](https://www.kaggle.com/datasets/hamza0027/global-sales-orders-data#1)
2. Создайте окружение Python - `conda create -n "week_3" python=3.9`
3. Активируйте окружение Python - `conda activate week_3`
4. установите библиотеки из requirements.txt - `pip install -r requirements.txt`

## Описание входных данных

Этот набор данных содержит исторические записи о продажах из глобальной розничной сети. Он включает информацию о клиентах, сведения о товарах, статус заказа, географическое местоположение, размеры сделок и атрибуты, связанные с продажами.

### Характеристики

Набор данных включает:

**Информация о заказе**

- Номер заказа
- Дата заказа
- Статус заказа
- Номер строки заказа

**Информация о товаре**

- Строка товара
- Код товара
- Количество заказанных единиц
- Цена за единицу

**Информация о клиенте**

- Имя клиента
- Имя контактного лица
- Фамилия контактного лица

**Географическая информация**

- Город
- Штат
- Страна
- Территория
- Почтовый индекс

**Бизнес-показатели**

- Размер сделки
- Квартал
- Месяц
- Год

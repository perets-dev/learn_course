# Демонстрация PCA и Truncated SVD на датасете Ames Housing

## Инструкция

1. Создайте окружение Python - `conda create -n "week_6" python=3.11`
3. Активируйте окружение Python - `conda activate week_6`
4. установите библиотеки из requirements.txt - `pip install -r requirements.txt`

## Датасет

**Ames Housing** — Dean De Cock, *"Ames, Iowa: Alternative to the Boston Housing Data as an
End of Semester Regression Project"*, Journal of Statistics Education, Vol. 19, No. 3 (2011).

* 2930 сделок с жилой недвижимостью в г. Эймс, Айова, 2006–2010 гг.
* 82 признака: 39 числовых, 43 категориальных
* Источник CSV: `https://raw.githubusercontent.com/wblakecannon/ames/master/data/housing.csv`
  (ноутбук 1 скачивает файл сам, если его нет локально)

Датасет выбран потому, что он одновременно даёт материал для всех этапов демонстрации:
пропуски двух разных природ (структурные и MAR), опечатки в датах, описанные автором выбросы,
номинальные и порядковые категории, сильную мультиколлинеарность (нужна для PCA) и 21
категориальный признак, который после one-hot даёт разреженную матрицу (нужна для Truncated SVD).

## Структура

```
01_PCA_demo.ipynb            подготовка данных + метод главных компонент
02_truncated_SVD_demo.ipynb  усечённое сингулярное разложение
data/raw/AmesHousing.csv     исходные данные
data/processed/              результаты очистки и снижения размерности
artifacts/                   обученные scaler / PCA / OneHotEncoder / TruncatedSVD
```

Ноутбуки выполняются по порядку.

## Ноутбук 1 — `01_PCA_demo.ipynb`

1. Загрузка и первичный обзор
2. Преобразование типов: `MSSubClass` (число → категория), 24 порядковые шкалы → монотонный код;
   ординальность проверена графиком монотонности медианной цены
3. Пропуски: доказано, что `NA` в 15 колонках означает «объекта нет» (100% согласованности с нулём
   в связанной числовой колонке) → `"None"` / `0`; `LotFrontage` — медиана внутри района
   (показано, что глобальная медиана занижает дисперсию)
4. Выбросы: починка опечатки `GarageYrBlt = 2207`; удаление 3 недостроенных домов
   (`SaleCondition = Partial`); удаление 7 вырожденных признаков; `log1p` для 22 скошенных
5. 15 новых признаков (`TotalSF`, `HouseAge`, `OverallGrade`, `LivAreaPerRoom`, …)
6. Диагностика мультиколлинеарности — мотивация PCA
7. **Теория PCA**: отношение Рэлея и теорема Куранта–Фишера, двойственность
   «максимум дисперсии ⟺ минимум ошибки реконструкции», связь с SVD, роль стандартизации,
   условия применимости
8. PCA тремя способами (`eigh`, `svd`, `sklearn`) — совпадение до 1e-13
9. Выбор `k`, нагрузки, интерпретация, проверка формулы ошибки реконструкции
10. Ridge-регрессия на сжатых признаках

**Ключевой результат:** PC1 = ось «размер × качество дома», корреляция с log(цена) **0.914**,
хотя PCA обучался без целевой переменной. 20 компонент из 67 дают R² = 0.899 против 0.912
на полном наборе.

## Ноутбук 2 — `02_truncated_SVD_demo.ipynb`

1. Загрузка артефактов ноутбука 1
2. **Теория SVD**: существование для любой матрицы, связь с собственными векторами $A^\top A$,
   геометрия «поворот → растяжение → поворот» (с визуализацией)
3. **Теорема Эккарта–Янга–Мирского** с идеей доказательства
4. Тождество `TruncatedSVD(центрированная X) ≡ PCA(X)` — проверено численно (расхождение 1e-13)
5. Что центрирование делает с разреженностью: плотность one-hot матрицы 11% → 100%
6. Truncated SVD на разреженной матрице: спектр, две метрики важности, интерпретация нагрузок
7. Численная проверка обеих формул теоремы + сравнение со случайным подпространством того же ранга
8. `arpack` vs `randomized`; демонстрация на матрице 50 000 × 20 000 (8 МБ CSR против 8 ГБ плотной)
9. SVD-признаки в регрессии
10. Сводная таблица PCA vs Truncated SVD

**Ключевой результат:** 30 SVD-компонент дают R² = 0.911 — **выше**, чем все 186 one-hot столбцов
(0.907), при вшестеро меньшей размерности. Первая компонента некентрированной матрицы несёт
60% энергии, но лишь 1.4% дисперсии: это направление среднего (corr с вектором средних = 0.9999).

Итог: 82 исходные колонки → 61 ортогональный признак (31 PCA + 30 SVD), R² = 0.911.

# Преобразования признаков

## Инструкция

1. Создайте папку data и поместите туда файл [paddydataset.csv](https://archive.ics.uci.edu/dataset/1186/paddy+dataset#1)
2. Создайте окружение Python - `conda create -n "week_5" python=3.11`
3. Активируйте окружение Python - `conda activate week_5`
4. установите библиотеки из requirements.txt - `pip install -r requirements.txt`

## Описание входных данных

Рис, выращиваемый из семян риса, обеспечивает продовольствием почти половину населения планеты. Для удовлетворения растущего спроса на продовольствие данное исследование направлено на повышение урожайности риса с использованием машинного обучения (МО) для прогнозирования факторов, влияющих на рост риса. Этот набор данных содержит информацию сельскохозяйственного и экологического характера, касающуюся выращивания риса на заливных полях. В него включены сведения о методах ведения хозяйства, состоянии почвы, погодных условиях и урожайности.
